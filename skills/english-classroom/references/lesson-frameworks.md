# Lesson Frameworks

## PPP — Presentation, Practice, Production
Best for: a single, clear grammar or vocabulary target. In the lesson plan itself, label this stage **Grammar Focus** rather than "Presentation" (see SKILL.md's plan structure).
- **Presentation**: introduce the target language in context (a short text, dialogue, or situation), elicit meaning/form/pronunciation from students before explaining
- **Practice**: controlled exercises (gap-fill, matching, drilling) where accuracy matters most
- **Production**: freer use in speaking or writing where fluency matters more than accuracy; teacher monitors, doesn't interrupt

## TBL — Task-Based Learning
Best for: exam prep, business English, project-oriented classes; language emerges from completing a real task rather than being pre-taught.
- **Pre-task**: introduce the task and topic, activate relevant vocabulary
- **Task cycle**: students complete the task (e.g. plan an event, negotiate a deal, solve a problem) in groups; teacher monitors without correcting
- **Report**: groups present outcomes
- **Language focus**: afterward, address language issues that came up during the task (this is where explicit grammar/vocab teaching happens, reactively)

## ESA — Engage, Study, Activate
Best for: mixed-skill lessons, more flexible ordering than strict PPP (Study and Activate stages can loop).
- **Engage**: get students emotionally/mentally involved (game, image, question) — not necessarily topic-related
- **Study**: focus on specific language form/meaning
- **Activate**: students use language freely; can cycle back to Study if gaps appear

## Receptive skills (reading/listening): Pre- / During- / Post-
Best for: any lesson centered on a reading or listening text.
- **Pre-**: build schema — predict from title/image, pre-teach only the vocab that blocks comprehension (not everything unfamiliar)
- **During-**: tasks while reading/listening — gist task first (skim/scan for general idea), then detail task (specific information, inference)
- **Post-**: react to content (discussion, opinion) and/or extract language for study (useful phrases, structures noticed in the text)

## Choosing a framework
- Single grammar/vocab point, want controlled accuracy first → **PPP**
- Exam prep, real-world task simulation, business context → **TBL**
- Want more energy/flexibility, mixed levels → **ESA**
- Lesson is built around a reading or listening text → **Pre/During/Post**

## Group classroom notes

The frameworks above apply to a class with these adjustments.

- **PPP**: Presentation is whole class. Practice starts individually, then students check answers in pairs. Production runs in pairs or groups, with Support, Core, and Stretch versions of each task.
- **TBL**: the task cycle runs in groups, then each group reports back. The language focus stage uses errors collected across groups, so the teacher should monitor several groups and note common mistakes.
- **ESA**: Engage is a whole-class or pair warm-up. Study is taught once at the median level. Activate runs in tiered groups.
- **Receptive skills**: pre-task prediction in pairs, during-task checks individually with a pair comparison, post-task discussion in groups.
- In every framework, plan for monitoring: decide where the teacher stands, which groups to visit first, and what the early finishers do.
